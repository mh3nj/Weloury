# Weloury

This release preserves the original Weloury desktop project as a complete reference point for its development.

## What's included

- **Desktop application:** the native Tauri desktop entry point in `apps/desktop`.
- **Go backend:** system inspection, process and service management, storage, networking, containers, health checks, logs, and automation.
- **React and TypeScript interface:** a unified interface for working with the system tools.
- **Local data storage:** SQLite persistence for application data and settings.
- **Desktop integration:** native application lifecycle and communication with the local backend.

## Technology

- Go
- Rust
- Tauri 2
- React
- TypeScript
- SQLite

## Installers

Windows MSI and NSIS installer packages are provided as release assets when uploaded by the maintainer. Check the Assets section of this release for the actual files.

## Project status

Weloury is no longer being developed as a standalone application. Its work is being carried forward together with Stellarie into a larger commercial application, which is being rewritten in Rust.

This release preserves the original Weloury project as a reference to its development. No further standalone feature development is planned.
